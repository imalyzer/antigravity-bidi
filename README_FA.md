# راهنمای کامل نگهداری، نصب و مدیریت پچ راست‌چین Antigravity

این ریپازیتوری شامل ابزارها، سورس‌ها و اسکریپت‌های سبک برای فعال‌سازی موتور هوشمند راست‌چین و تفکیک خط‌به‌خط فارسی/انگلیسی (BiDi Engine) در چت و ادیتور متنی **Google Antigravity 2.0** است.

---

## ۱. فایل‌های اجرای سریع (با ۱ کلیک)

دو فایل اجرایی `.bat` برای راحتی کاربر در ریشهٔ پوشه قرار دارند:

| نام فایل | کاربرد | چه زمانی استفاده شود؟ |
| :--- | :--- | :--- |
| **`1_Apply_Patch.bat`** | **نصب و پچ هوشمند خودکار** | بعد از نصب اولیه Antigravity یا هر زمان که گوگل نسخهٔ جدیدی منتشر کرد. این اسکریپت نسخهٔ جدید گوگل را از سیستم استخراج کرده، موتور BiDi را تزریق و مجدداً بسته‌بندی می‌نماید (بدون از دست رفتن قابلیت‌های جدید گوگل). |
| **`2_Restore_Original.bat`** | **بازگردانی به تنظیمات کارخانه** | هر زمان که خواستید Antigravity را بدون هیچ تغییری به حالت خام و اولیهٔ گوگل بازگردانید. |

---

## ۲. سناریوهای کاربردی

### سناریو ۱: نصب اولیه یا تعویض ویندوز
1. نرم‌افزار Antigravity را نصب کنید.
2. این ریپازیتوری را دانلود کرده یا کلون کنید:
   ```cmd
   git clone https://github.com/imalyzer/antigravity-bidi.git
   ```
3. روی فایل **`1_Apply_Patch.bat`** دابل‌کلیک کنید.
   * اسکریپت به صورت خودکار پوشهٔ کاربری سیستم (`%LOCALAPPDATA%`) را پیدا می‌کند.
   * از نسخهٔ دست‌نخورده فعلی یک بک‌آپ ایمن می‌گیرد.
   * پچ را اعمال کرده و برای باز کردن برنامه تایید می‌گیرد.

---

### سناریو ۲: آپدیت شدن Antigravity توسط گوگل
هنگامی که گوگل نسخهٔ جدیدی منتشر می‌کند، فایل هسته ریست شده و برنامه به حالت چپ‌چین برمی‌گردد.
* **راه‌حل:** مجدداً روی **`1_Apply_Patch.bat`** دابل‌کلیک کنید!
* **چرا این اسکریپت ایمن است؟**
  این پچر، یک فایل قدیمی را جایگزین نمی‌کند؛ بلکه کدهای نسخهٔ جدید گوگل را مستقیماً از سیستم شما خوانده، ۱۰۰٪ امکانات جدید گوگل را حفظ کرده و فقط موتور راست‌چین را به آن اضافه می‌کند.

> **پیش‌نیاز:** برای اجرای پچر، نیاز است که [Node.js](https://nodejs.org) (نسخه ۱۸ به بالا) روی سیستم نصب باشد.

---

### سناریو ۳: جلوگیری از آپدیت ناخواسته در تنظیمات
اگر ترجیح می‌دهید برنامه روی نسخهٔ فعلی بماند و خودسرانه آپدیت نشود:
1. در Antigravity روی علامت **چرخ‌دنده (Settings)** در پایین صفحه کلیک کنید.
2. وارد **Editor Settings** شوید.
3. در کادر جستجو عبارت **`update mode`** را تایپ کنید.
4. مقدار **Update: Mode** را روی **`none`** یا **`manual`** قرار دهید.
5. برنامه را ببندید و مجدداً باز کنید.

---

### سناریو ۴: بازگردانی کامل به حالت اولیه
هر زمان مایل بودید پچ را حذف کنید، کافی است فایل **`2_Restore_Original.bat`** را اجرا کنید. این اسکریپت فایل بک‌آپ نسخه اصلی را فوراً برمی‌گرداند.

---

## ۳. ساختار فایل‌های مخزن

```text
antigravity-bidi/
├── 1_Apply_Patch.bat              # [اجرای سریع] نصب و آپدیت خودکار پچ
├── 2_Restore_Original.bat         # [اجرای سریع] بازگردانی ۱ کلیکه به تنظیمات اولیه
├── LICENSE                        # لایسنس MIT (اعطا شده به imalyzer)
├── package.json                   # اسکریپت‌های npm run patch و npm run restore
├── README.md                      # مستندات و معماری فنی سیستم به زبان انگلیسی
├── README_FA.md                   # همین راهنما به زبان فارسی
├── AGENT_GUIDE.md                 # راهنمای فنی برای ایجنت‌های هوش مصنوعی (انگلیسی)
├── patch/
│   └── bidi_engine.js             # سورس موتور BiDi و هوک‌های Lexical در Main World
└── scripts/
    ├── smart_patch.js             # موتور استخراج، تزریق هوشمند و پکینگ ASAR
    ├── smart_update_patch.bat     # لانچر بچ اسکریپت برای پچ پویا
    └── restore_original.bat       # لانچر بچ اسکریپت برای بازگردانی بک‌آپ
```
